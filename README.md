## 研究问题

1. 中国 20～24 岁成年人（分性别）的身高是否近似服从正态分布？
2. 若近似正态，其样本均值、标准差与理论正态曲线、Q-Q 图的吻合程度如何？
3. 若偏离正态（如女性样本），偏离体现在何处、对“现实数据近似正态”的论断意味着什么？

---

## 数据来源

- **数据库**：China Health and Nutrition Survey（CHNS，中国健康与营养调查）
- **调查轮次**：2011 年
- **原始记录数**：518 条（20～24 岁、含身高字段）
- **缺失剔除**：45 条（身高缺失）
- **有效样本**：473 条 → 男性 220 条、女性 253 条
- **获取方式**：CHNS 为受限访问数据库，需研究者向官方申请授权后下载；原始数据文件**不随本仓库发布**（见 `data/README.md`）。

## 数据清洗

1. 从体检文件 `pexam_00` 中筛选 2011 年、年龄 20～24 岁、含身高测量的受访者。
2. 剔除身高缺失记录 45 条，得到有效样本 473 条。
3. 按受访者性别分组，分别进行描述统计与正态性检验。
4. 个体级派生数据（如 `CHNS_height_clean.csv`）体积大且含微观记录，**不随仓库发布**，仅保留汇总结果与脚本。

---

## 方法

- **描述统计**：均值、中位数、方差、标准差、偏度、超额峰度、最值。
- **正态性检验**：Shapiro-Wilk 检验（完整样本检验）。
- **可视化**：按样本均值与标准差叠加理论正态密度曲线（直方图）、Q-Q 图。
- **经验覆盖比例**：分别计算 μ±1σ、μ±2σ、μ±3σ 的实际覆盖率，与理论值 68.27% / 95.45% / 99.73% 对比。

## 主要结果

| 指标 | 男性 | 女性 |
| --- | --- | --- |
| 样本量 n | 220 | 253 |
| 均值（cm） | 171.5614 | 159.5917 |
| 标准差（cm） | 6.8218 | 6.0802 |
| 偏度 | 0.0107 | -0.3614 |
| 超额峰度 | -0.0150 | 0.5907 |
| Shapiro-Wilk W | 0.992062 | 0.987611 |
| Shapiro-Wilk P | 0.2799 | 0.0281 |
| μ±3σ 覆盖率 | 100.00% | 99.60% |

- 男性（P=0.2799 > 0.05）：**不能拒绝**正态性原假设，身高近似服从正态分布。
- 女性（P=0.0281 < 0.05）：在 5% 水平**拒绝**正态性原假设；偏度 -0.36、超额峰度 0.59 显示轻度左偏与尖峰，但 μ±3σ 覆盖率仍达 99.60%，整体仍接近正态。

## 复现方式

1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
2. 向 CHNS 官方申请 2011 年数据，将 `pexam_00.sas7bdat` 等放入本地 `data/`（见 `data/README.md`）。
3. 运行：
   ```bash
   python scripts/audit_2011_sample.py
   python scripts/audit_chns_population.py
   python scripts/analyze_height_2011_normality.py
   ```
   脚本会读取本地 `data/`，重新计算并生成与论文一致的结果与图 5-1~5-4。
