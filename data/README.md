# data/ 目录说明

本目录**不包含** CHNS 原始数据文件，仅说明数据的使用方式与本地放置方法。原始数据受访问协议约束，不随仓库发布。

## 1. 原始数据来源

- **数据库**：China Health and Nutrition Survey（CHNS，中国健康与营养调查）
- **官方获取**：https://www.cpc.unc.edu/projects/china （需注册并签署数据使用协议后下载）
- **本研究所用**：2011 年调查轮次

## 2. 本分析使用的关键变量

| 文件（本地名） | 关键变量 | 用途 |
| --- | --- | --- |
| `pexam_00.sas7bdat` | 身高测量（如 `height`）、受访者 ID（`ind_id`）、调查轮次（`wave`）、年龄、性别 | 提取 20～24 岁身高，进行描述统计与正态性检验 |
| `mast_pub_12.sas7bdat` | 受访者人口学信息（ID、年龄、性别等） | 与体检文件按 ID 匹配，核对样本量口径 |

> 具体变量名以 CHNS 官方数据字典（codebook）为准；脚本中已对变量名做集中定义，便于按本地数据字典调整。

## 3. ID 匹配与年龄定义

- 以受访者唯一 ID 关联体检文件与人口学文件，确保身高记录能对应到正确的性别与年龄。
- **年龄定义**：按 CHNS 提供的年龄字段，筛选 **20～24 岁（含端点）** 受访者；调查轮次限定为 **2011 年（`wave`=2011）**。
- 身高缺失记录（45 条）予以剔除，得到有效样本 473 条（男 220 / 女 253）。

## 4. 为何不上传原始数据

1. **合规**：CHNS 为受限访问数据，使用协议禁止公开再分发。
2. **体量**：`.sas7bdat` 原始文件较大（本研究涉及 `pexam_00.sas7bdat` 约 192 MB、`mast_pub_12.sas7bdat` 约 2.8 MB），不适合纳入代码仓库。
3. **必要性**：论文结论仅依赖汇总级结果，个体级微观记录不是必要交付。

## 5. 本地放置方式（供复现）

如需在本地复现分析，请将官方下载的文件按如下结构放入本目录：

```
data/
├── pexam_00.sas7bdat     # 2011 年体检文件（含身高）
├── mast_pub_12.sas7bdat  # 人口学匹配文件
└── README.md             # 本文件
```

随后在仓库根目录运行：

```bash
pip install -r requirements.txt
python scripts/audit_2011_sample.py
python scripts/audit_chns_population.py
python scripts/analyze_height_2011_normality.py
```

脚本读取 `data/` 下的本地文件后，将重新计算并生成与论文一致的表 5-1、表 5-2 与图 5-1~5-4。
